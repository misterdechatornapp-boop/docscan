# สแกนง่าย

เว็บแอป (PWA) สำหรับ iPhone: ถ่ายรูปเอกสาร → หาขอบกระดาษอัตโนมัติ → ดัดภาพให้ตรง + ลบเงา → เรียงหน้า → ส่งออก PDF/JPG
**ลิงก์แอป:** https://misterdechatornapp-boop.github.io/docscan/

ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก · ข้อมูลทั้งหมดเก็บในเครื่อง (IndexedDB) · ไม่มีโฆษณา

## ทดสอบบนคอมพิวเตอร์

```bash
node serve.js
```

เปิด http://localhost:8796 (ตั้งเบราว์เซอร์เป็นขนาดมือถือจะเห็นหน้าตาเหมือนบน iPhone)

ลองบน iPhone ที่อยู่ Wi-Fi เดียวกัน: เปิดที่อยู่ `http://192.168.x.x:8796` ที่เซิร์ฟเวอร์พิมพ์ออกมา
> แบบนี้ถ่ายรูป/ส่งออกได้ แต่ **ยังไม่ทำงานออฟไลน์** เพราะ iOS เปิดระบบออฟไลน์ (service worker) ให้เฉพาะเว็บ HTTPS
> ถ้า iPhone เปิดไม่ขึ้น ให้อนุญาต Node.js ใน Windows Firewall (เครือข่ายส่วนตัว)

## ติดตั้งบน iPhone แบบใช้จริง
1. เอาโฟลเดอร์นี้ขึ้นเว็บ HTTPS ฟรี (GitHub Pages / Netlify / Cloudflare Pages) — **ไม่ต้องอัปโหลด** `node_modules/`, `tools/`, `serve.js`
2. เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าจอโฮม 1 ครั้งตอนมีเน็ต (โหลดตัวหาขอบกระดาษ ~10 MB) หลังจากนั้นใช้ออฟไลน์ได้

## ปล่อยเวอร์ชันใหม่
1. แก้เลขเวอร์ชันให้ตรงกันใน `js/config.js` และ `sw.js` (`VERSION`)
2. `git commit` แล้ว `git push` — GitHub Pages อัปเดตเองภายใน ~1 นาที → แอปบน iPhone จะขึ้นแถบ “มีเวอร์ชันใหม่ · อัปเดต”

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `js/app.js` | หน้าจอทั้งหมด: รายการ/โฟลเดอร์/ค้นหา, เอกสาร (ลากเรียงหน้า), หน้าเดี่ยว, ถังขยะ, ตั้งค่า, ส่งออก |
| `js/editor.js` | หน้าปรับภาพ: ลากมุม (มีแว่นขยาย) → ฟิลเตอร์ ปรับสี/สีเทา/ขาวดำ/ต้นฉบับ + หมุน |
| `js/cv-worker.js` | OpenCV ใน worker: หาขอบกระดาษ, ดัดภาพ (perspective), ลบเงา, ขาวดำ |
| `js/imaging.js` | โหลด/ย่อภาพ (ด้านยาวสุด 2800 px), เรียก worker |
| `js/exporter.js` | สร้าง PDF (pdf-lib) / JPG + เมนูแชร์ของ iOS (บันทึกลงไฟล์ อีเมล พิมพ์ LINE) |
| `js/db.js` | IndexedDB: docs / pages / folders / meta |
| `sw.js` | service worker เก็บไฟล์แอปไว้ใช้ออฟไลน์ |
| `vendor/` | ไลบรารี (คัดลอกด้วย `npm run vendor`) |
| `tools/make-icons.js` | สร้างไอคอนแอป (`npm run icons`) |

แต่ละหน้าเก็บภาพต้นฉบับไว้ด้วย จึงกลับมาแก้ขอบ/ฟิลเตอร์/หมุนภายหลังได้โดยภาพไม่เสื่อม

## ฟีเจอร์เด่น
- **กล้องในแอป**: ไฟฉาย, กรอบเอกสารสด, โหมด **ต่อเนื่อง** (ถ่ายรัว จัดขอบ+ฟิลเตอร์อัตโนมัติเบื้องหลัง) / **ทีละหน้า** (ปรับทุกภาพ)
- หน้าที่หาขอบไม่เจอติดป้าย **ตรวจขอบ** ให้มาแก้ทีหลัง
- **กระดาษโค้ง**: หาขอบโค้งอัตโนมัติ + ลากจุดกลางขอบเพื่อดัดเอง → ยืดให้บรรทัดตรง (Coons patch ใน `js/cv-worker.js`)
- **ดัดเส้นให้ตรง** (กระดาษป่อง/โค้งกลางแผ่น): ใช้เส้นตารางและแนวบรรทัดในเอกสารเป็นตัวอ้างอิง ฟิตสนามการเลื่อนแบบพหุนามแล้ว remap · ปิด/เปิดได้ในหน้าฟิลเตอร์
- ลบเงา + แถบคอนทราสต์ · แตะค้างเพื่อเลือกหน้า → ส่งออก / เปลี่ยนฟิลเตอร์ / ลบ เฉพาะที่เลือก

## ยังไม่ได้ทำ (ระยะถัดไป)
- ซิงค์ Google Drive + แชร์โฟลเดอร์ให้เพื่อน
- OCR อ่านข้อความไทย/อังกฤษ (ค้นหาจากข้อความในเอกสาร)
- นำเข้าไฟล์ PDF, แทรกหน้าเปล่า
- พิมพ์ตรงไป PeriPage A40 (พักไว้ก่อน)
